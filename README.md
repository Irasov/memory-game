# memory-game

Задание: https://github.com/rolling-scopes-school/tasks/tree/master/tasks/memory-game

Создайте игру на поиск пар: игрок открывает карточки и запоминает их расположение, чтобы найти все совпадения за наименьшее число ходов.

## Правила игры

1.Игра начинается автоматически при первой загрузке и каждой перезагрузке страницы. Все 16 карточек перемешаны и лежат рубашкой вверх, счётчик ходов равен 0, найденных пар — 0 из 8. Игрок сразу может открывать карточки.

2.Игрок открывает одну карточку, затем другую. Один ход — открытие двух разных доступных карточек, независимо от того, совпали они или нет.

3.Если изображения совпали, обе карточки остаются открытыми до конца игры. Счётчик найденных пар увеличивается на 1.

4.Если изображения различаются, обе карточки остаются видимыми примерно секунду, затем закрываются. Пока игрок рассматривает несовпавшую пару, открыть другие карточки нельзя.

5.Когда найдены все 8 пар, игра завершена. Автоматически откройте модальное окно с сообщением о победе, итоговым количеством ходов и кнопками «Новая игра» и «Закрыть».

6.В хедере расположены кнопки «Новая игра» и «Таблица лидеров». «Новая игра» начинает игру заново: карточки перемешиваются и закрываются, счётчики обнуляются. «Таблица лидеров» открывает сохранённые результаты в модальном окне.
